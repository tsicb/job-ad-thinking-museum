# 求人広告を、3つで考える。

> 覚えるために分ける。考えるためにつなぐ。

求人広告を「素材・価値・伝達」という3つのレンズから捉え、さらに各テーマを3つずつ展開して、**思考の現在地を見失わずに考える**ためのデジタル科学館です。

## このサイトについて

- **知る**：3分割の目的、3つのレンズ、分類の限界
- **見る**：3×3×3の思考地図、13組の記憶フレーズ、縦・横・渡る移動
- **試す**：一文のレンズ切替、訴求の弱い原稿の診断、再構築クイズ

これは求人広告を厳密に網羅する分類体系ではありません。記憶・想起・着眼点の切り替えを支援する、実務向けの仮説的な思考モデルです。3分割が心理学的に普遍最適という主張はしていません。

## ローカル確認

静的ファイルを配信するだけで動作します。リポジトリ直下で `python -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。外部フレームワークやビルド処理は不要です。

## GitHub Pages

`Settings → Pages → Build and deployment → Deploy from a branch → main / (root)` を選ぶと、通常は `https://tsicb.github.io/job-ad-thinking-museum/` で公開できます。GitHub Pagesの設定完了とビルド成功を確認してください。

## ファイル

- `index.html`：サイトの本体
- `styles.css`：レイアウト・配色・レスポンシブ
- `app.js`：展示ナビゲーション、思考マップ、レンズ、診断、再現テスト
- `data/taxonomy.json`：3層27テーマと13組の記憶フレーズ
- `docs/exhibition-design-v0.1.md`：展示設計書・教科書の下書き
- `docs/CHANGELOG.md`：更新履歴

## 編集方針

- 求人広告の**事実**と、求職者にとっての**価値の仮説**を混同しない
- テーマの重複所属を認め、分類先より思考の出発点を優先する
- 27分類を埋めるチェックリストにはしない
- 法令上の必須表示事項は、このモデルとは別途確認する
- 第3層より先の機械的な分岐は当面作らない
