# CHANGELOG

## v0.1.0 — 2026-11-15

### 初期実装
- GitHub Pages向け静的サイト「求人広告を、3つで考える。」を制作
- 3展示室「知る・見る・試す」と、各3展示の教科書を実装
- 3×3×3の思考マップを探索できるUIを追加
- 40ノード（全体1／第1層3／第2層9／第3層27）をJSONで管理
- 13組の記憶フレーズを見ながら再構築する展示を追加
- 「縦・横・渡」の代表経路を確認する展示を追加
- 同じ一文を3つのレンズで見つめ直す実験を追加
- 訴求の弱い仮想求人を、素材不足・価値の仮説・伝達の課題から診断する展示を追加
- 13組の再現・穴埋め練習を追加（サーバーへの結果保存なし）
- 端末幅に応じたレイアウトと、キーボード操作を考慮したボタン類を整備

### 位置づけ
この段階では分類の有効性・記憶効果・広告成果は未検証。教材と探索UIの動作確認を重視した初期版。
